## Stage 2 review (security-reviewer, 2026-11-14)

The stage added design documents only. The first review ended in "fail": no path around the governor, but five high findings where the rate guard, the one physical-safety control, would have been blind as designed. All were fixed in the documents before the PR, and a second review of the fixes ended in "pass with follow-ups". Those follow-ups are fixed too. No secrets, machine paths or personal details were found.

| ID    | Finding                                                                                                          | Severity | Status | Reasoning or fix                                                                                                                                                                           |
| ----- | ---------------------------------------------------------------------------------------------------------------- | -------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| S2-H1 | The rate guard judged one "output" number, so a swap between colours at a constant level was not a swing         | High     | Fixed  | SPEC S3.1a: the guard watches each channel's drive and a luminance estimate. P-rate generates colour-only streams.                                                                         |
| S2-H2 | Broadcast, group and unaddressed frames reach gear the shadow does not model                                     | High     | Fixed  | SPEC S3.1b and ADR 0004: such frames are also judged against a worst-case phantom driver. The scan asks for unaddressed gear.                                                              |
| S2-H3 | Governor state carried over from the simulator to the hardware, and across reconnects                            | High     | Fixed  | SPEC R1.1a and R1.8: the hardware has its own state, reset on every connect and target change.                                                                                             |
| S2-H4 | Unlocked RESET and IDENTIFY DEVICE could pass the guard, and a script could use a person's unlock                | High     | Fixed  | IDENTIFY DEVICE is refused always. RESET is a full swing, once in 10 s, followed by OFF. Unlock-gated commands are accepted from a person only.                                            |
| S2-H5 | The guard trusted fade settings that are unconfirmed, editable and importable                                    | High     | Fixed  | SPEC S3.7 and R1.6: instant-step assumption on hardware until the fade is read back and the behaviour is marked confirmed in code. Simulator settings never reach the hardware's governor. |
| S2-M1 | Frames queued in the server could run after panic's OFF                                                          | Medium   | Fixed  | SPEC 9: every stop drops the queue first, then TERMINATE and OFF. Hasseb timeout 250 ms.                                                                                                   |
| S2-M2 | A transport fault was treated as "not sent"                                                                      | Medium   | Fixed  | SPEC R1.9: the state the frame could have changed becomes unknown.                                                                                                                         |
| S2-M3 | The leg definition allowed a staircase of small steps, and the rule table was not default deny                   | Medium   | Fixed  | A leg is a maximal monotonic run across commands. S3.9: every transaction is judged by its predicted effect. Unnamed commands are refused.                                                 |
| S2-M4 | The property tests covered one clause of S3                                                                      | Medium   | Fixed  | TEST_PLAN: every clause asserted on the trace, with generators for each way round found here.                                                                                              |

No element fullscreen, and `fullscreen=()`.                                                                                                        |
